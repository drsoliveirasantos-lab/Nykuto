# Base RSI / tendances — Nykuto

Établie le 2026-09-09.

## Livrables

- dossier_recherche.html : lecture autonome, recherche dans les fiches et références cliquables.
- dossier_recherche.md : dossier éditable.
- sources.json : 30 références avec statut et limites.
- connaissances.json : 56 fiches sourcées ; propositions distinguées des définitions.
- catalogue_charts.json : 18 spécifications de figures et contre-exemples ; aucune image tierce recopiée.
- hypotheses_a_tester.json : 6 protocoles candidats, tous désactivés et non exécutables.
- tests_acceptation.json : 24 tests à implémenter sur le moteur futur.
- contrat_analyse.schema.json : schéma de sortie documentaire proposé, sans interface d’ordre.
- exemple_analyse_fictif.json : exemple synthétique, pas une observation de marché.
- controle_structure.json : contrôles locaux du pack, distincts de tests de trading.

## Utilisation ultérieure

Importer les fiches dans une base de recherche documentaire ou une interface éducative. Adapter ensuite le schéma au code réel après audit du dépôt et du flux. Implémenter les calculs et le cahier de tests avant tout backtest. Compléter les paramètres manquants des protocoles, puis évaluer leur apport séparément.

Cette livraison n’a modifié aucun site, aucun dépôt ni aucun compte. Elle n’a téléchargé aucun historique de cotations pour une simulation, exécuté aucun backtest et entraîné aucun modèle. Les contrôles effectués portent uniquement sur la structure des fichiers, les références internes et la conformité de l’exemple au schéma.

Les sources sont répertoriées pour consultation et attribution ; leurs images et articles ne sont pas redistribués. Aucun taux de réussite ni réglage rentable n’est revendiqué.
